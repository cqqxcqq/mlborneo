# MLBorneo
Interactive forest monitoring and forest illustration exhibit.

Requires Node.js 22.12 or newer. Run npm ci, npm run build, then npm start and open http://127.0.0.1:4173/.

The overview rotates automatically while it is on screen. Selecting a cell keeps the overview moving. The operating system’s reduced-motion preference keeps it still.

The public folder contains the exhibit’s processed runtime assets. Research-data regeneration uses the separate research workspace.
